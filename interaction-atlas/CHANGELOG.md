# Changelog

## 0.1.22

Changelog starts here; versions before 0.1.22 were not individually tracked.

Object-centric visual analytics for when and how objects co-occur over
their lifecycles: an upper-triangular atlas opens into a
lifecycle-interaction tomogram with exact rectangular or lasso-bin
selection, inversion, side-by-side remainder comparison, and source-bound
lasso cohorts consumable by compatible views.
