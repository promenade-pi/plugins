# Synchronization Lens

An object-centric dependency view that makes the final open prerequisite for a target object visible. The current view includes a polished local scenario so its interaction model is immediately explorable; its data shape is deliberately separated into `targetObject`, `relatedObjects`, `events`, `synchronizationRule`, and `insights` for connection to computed OCEL evidence.

Click an item to trace it through the synchronization gateway. Move the event-time control past 23:34 to satisfy the final prerequisite and release the shipment.
