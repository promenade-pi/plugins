# Changelog

## 0.2.3 — 2026-09-18

- Corrected the `homepage` and `repository` URLs. The plugins live in one
  repository, [`promenade-pi/plugins`](https://github.com/promenade-pi/plugins),
  not one repository per plugin under a `promenade-lab` organisation that was
  never created. Metadata only — no functional change.

## 0.2.2 — 2026-08-16

- Ships this changelog as its own tab in the plugin's detail panel.

## 0.2.1 — 2026-08-16

- Relabelled **Alpha Miner (Classic)**, with an updated description: this is
  van der Aalst's original 2004 algorithm, kept mainly to teach its own
  well-known limitations (no noise tolerance, no short loops, no duplicate
  labels). Heuristics Miner or Inductive Miner is the better default on a
  real, noisy log. No change to the algorithm itself.

## 0.2.0 and earlier

Version history before this file was introduced is not tracked.
