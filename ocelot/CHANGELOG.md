# Changelog

## 0.2.6

Changelog starts here; versions before 0.2.6 were not individually tracked.

Ocelot (rwth-pads/ocelot) ported into an OCEL 2.0 inspector: an
object-type / event-type relationship graph, paginated Objects and Events
tables with a per-object lifecycle and relations explorer, and a
cleaned-up OCEL overview standing in for the core one. Every table pages
real LIMIT/OFFSET SQL — nothing is loaded into the browser wholesale.
