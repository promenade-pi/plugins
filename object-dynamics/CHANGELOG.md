# Changelog

## 0.1.3

Changelog starts here; versions before 0.1.3 were not individually tracked.

A family of independent object-centric exploration views over an OCEL 2.0
log: Multiplicity, Type Signatures, Lifecycle Repetition, Activity Timing,
Attribute History, Attribute Distribution, plus an optional Overview. Each
opens as its own dockable panel — there is no shared tabbed shell — and
every aggregation runs as SQL against the log's own relational tables,
never materialised wholesale into the browser.
